# Evidências do quadro Kanban

Esta pasta guarda as capturas de tela do quadro de tarefas (Trello, GitHub Projects, Jira
ou similar) usado para organizar o desenvolvimento.

**Precisa ser preenchida pelo desenvolvedor.** A IA não tem acesso ao quadro e não gera
capturas fictícias.

## Sugestão de conteúdo

Uma captura por fase, mostrando a transição das tarefas entre as colunas:

| Arquivo sugerido            | Momento                               |
| --------------------------- | ------------------------------------- |
| `01-planejamento.png`       | Início: backlog com as fases 1–6      |
| `02-infraestrutura.png`     | Fase 2 concluída                      |
| `03-modelagem.png`          | Fase 3 concluída                      |
| `04a-backend-cadastros.png` | Fase 4a concluída                     |
| `04b-backend-operacao.png`  | Fase 4b concluída                     |
| `05-qualidade.png`          | Fase 5 concluída                      |
| `06-documentacao-final.png` | Quadro final, com tudo em "Concluído" |

Colunas sugeridas: **Backlog → A fazer → Em andamento → Em revisão (validação humana) → Concluído**.

O histórico de commits (`git log --oneline`) serve de evidência complementar da
sequência das fases.
